14def draw_ou_noise(rng: np.random.Generator, length: int, channels: int, sigma: float, theta: float) -> np.ndarray: 

15 """A stationary Ornstein-Uhlenbeck path, sampled exactly at every step. 

16 

17 ``n[0] ~ N(0, sigma²)`` and ``n[t] = a n[t-1] + sigma sqrt(1 - a²) z[t]`` 

18 with ``a = exp(-theta)``: the path reverts to 0 at rate ``theta`` per step 

19 and keeps a stationary standard deviation ``sigma``. 

20 

21 This is the noise model for **one** window, drawn from that window's own 

22 generator. ``ou_noise`` is the batch side: it checks the batch, calls this 

23 function once per window with that window's generator (so a window's noise 

24 never depends on the batch it lands in), and applies the result additively 

25 or multiplicatively. The two are kept apart so that the model (the 

26 step-by-step recursion) can be read and checked on its own, without the 

27 batch code around it. ``length`` is any number of steps: a window's, or a 

28 whole series'. 

29 

30 Args: 

31 rng: The window's generator. 

32 length: Number of steps ``W``. 

33 channels: Number of channels ``C``. 

34 sigma: Stationary standard deviation. 

35 theta: Mean-reversion rate per step, ``> 0``; ``1 / theta`` is the 

36 correlation time in steps. 

37 

38 Returns: 

39 ``(W, C)`` array. 

40 """ 

41 a = np.exp(-theta) 

42 shocks = rng.standard_normal((length, channels)) 

43 path = np.empty((length, channels)) 

44 path[0] = sigma * shocks[0] 

45 step = sigma * np.sqrt(1.0 - a * a) 

46 for t in range(1, length): 

47 path[t] = a * path[t - 1] + step * shocks[t] 

48 return path

51def ou_noise( 

52 xs: np.ndarray, sigma: float, theta: float, rngs: list[np.random.Generator], mode: str = "additive" 

53) -> np.ndarray: 

54 """Add (or multiply by) Ornstein-Uhlenbeck noise. 

55 

56 A mean-reverting random walk: the noise wanders away from 0 and is pulled 

57 back at rate ``theta``, so successive steps are correlated over about 

58 ``1 / theta`` steps, like a slowly fluctuating sensor offset. Each window 

59 and channel draws its own stationary path. The support is **causal**: the 

60 noise at a step depends on the draws up to that step. 

61 

62 Args: 

63 xs: Batch of windows shaped ``(B, W, C)``, floating point. 

64 sigma: Stationary standard deviation, ``>= 0``; signal units in 

65 ``additive`` mode, a relative change in ``multiplicative`` mode. 

66 theta: Mean-reversion rate per step, ``> 0``. 

67 rngs: One generator per window, in batch order. 

68 mode: ``additive`` or ``multiplicative``. 

69 

70 Returns: 

71 The noisy batch, same shape and dtype. 

72 

73 Raises: 

74 ValueError: If ``xs`` is not a floating-point ``(B, W, C)`` stack, if 

75 there is not exactly one generator per window, or if ``mode`` is 

76 unknown. 

77 """ 

78 require_windows(xs, "ou_noise") 

79 require_generators(xs, rngs, "ou_noise") 

80 _, w, c = xs.shape 

81 noise = np.stack([draw_ou_noise(rng, w, c, sigma, theta) for rng in rngs]) if len(xs) else np.zeros_like(xs) 

82 return apply_noise(xs, noise, mode)
