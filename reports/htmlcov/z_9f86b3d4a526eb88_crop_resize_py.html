1"""Crop a central window, then resize it back to the sample shape: the math. 

2 

3``crop_resize(xs, fraction, top, left)`` is the pure numpy map; the 

4transformation class that wraps it into the unary contract lives in 

5``kcai_data_sampling_images.api.transformations.crop_resize``. 

6""" 

7 

8import numpy as np 

9 

10 

11def crop_resize(xs: np.ndarray, fraction: float, top: int = 0, left: int = 0) -> np.ndarray: 

12 """Keep the ``top:top+fraction*H`` by ``left:left+fraction*W`` window, resize back. 

13 

14 The crop is top-left anchored; the kept window is then nearest-neighbor 

15 resized back to ``(H, W)`` by index-replication, so the sample space stays 

16 intact. 

17 

18 Args: 

19 xs: Batch of image arrays shaped ``(B, H, W, C)``. 

20 fraction: Fraction ``(0, 1]`` of the image kept by the crop. 

21 top: Crop window top offset in pixels. 

22 left: Crop window left offset in pixels. 

23 

24 Returns: 

25 A batch of the same shape, uint8. 

26 

27 Raises: 

28 ValueError: If the crop window leaves the image (``top``/``left`` too 

29 large for the computed window). 

30 """ 

31 height, width = xs.shape[1], xs.shape[2] 

32 window_h: int = max(1, int(height * fraction)) 

33 window_w: int = max(1, int(width * fraction)) 

34 if top + window_h > height or left + window_w > width: 

35 raise ValueError( 

36 f"crop_resize: window {window_h}x{window_w} at ({top},{left}) leaves the {height}x{width} image" 

37 ) 

38 window = xs[:, top : top + window_h, left : left + window_w, :] 

39 

40 rows: np.ndarray = np.arange(height) * window_h // height 

41 cols: np.ndarray = np.arange(width) * window_w // width 

42 return window[:, rows[:, None], cols[None, :], :]
