1"""What goes into a transformation run: one generic decoded batch. 

2 

3A **batch is a row**: one ``load_batch_size`` chunk of a selection becomes a 

4:class:`Batch` — the chunk's source columns stay arrow-native (a pyarrow table, 

5the sample column dropped) and the sample column decodes **once** into a numpy 

6``(B, *sample)`` stack. Row ``i`` on every axis is the same sample: ``ids[i]``, 

7``columns`` slice ``i``, ``data[i]``. There is no ``Sample(x, y)`` and there is 

8no ``y`` — pyarrow wherever possible, numpy only where the sample math requires 

9it. Nothing here assumes images: the sample's space is declared by 

10``sample_axes`` and ``value_range``, both optional because a datatype package 

11fixes them on its own subclass (``-images`` defines 

12:class:`~kcai_data_sampling_images.api.selection.ImageBatch`). 

13""" 

14 

15from dataclasses import dataclass 

16 

17import numpy as np 

18import pyarrow as pa 

19 

20 

21@dataclass 

22class Batch: 

23 """One decoded chunk of a selection. 

24 

25 The batch is the in-memory authority on what a sample is, and nothing 

26 more: how batches relate to each other (streaming order) is a loader 

27 concern, and how many batches coalesce for execution changes nothing in 

28 the outputs (batch invariance). 

29 

30 Attributes: 

31 name: Unique name of the selection this batch belongs to. 

32 dataset: Names the reader (loader) that assembled the selection. 

33 ids: One row identifier per sample, in row order. 

34 columns: The chunk's source columns as a pyarrow table — the sample 

35 column is dropped — kept arrow-native for ledger pass-through. 

36 data: The decoded sample stack ``(B, *sample)``, one row per source 

37 row, in row order. 

38 sample_axes: Labels of the sample dimensions, or ``None`` when the 

39 datatype declares none. 

40 value_range: ``(low, high)`` domain of sample values, or ``None``. 

41 """ 

42 

43 name: str 

44 dataset: str 

45 ids: list[str] 

46 columns: pa.Table 

47 data: np.ndarray 

48 sample_axes: tuple[str, ...] | None = None 

49 value_range: tuple[float, float] | None = None 

50 

51 def __len__(self) -> int: 

52 """Return the number of rows (samples) in this batch.""" 

53 return len(self.data) 

54 

55 def row(self, index: int) -> "Batch": 

56 """Return a single-row batch: the sample at ``index``. 

57 

58 Slicing keeps the pyarrow columns and the numpy stack aligned with the 

59 ids, so a row is usable anywhere the whole batch is (the runner, a 

60 unary ``transform``), at ``(B=1, *sample)``. 

61 

62 Args: 

63 index: Row index into every axis of the batch. 

64 

65 Returns: 

66 The one-row batch. 

67 """ 

68 return Batch( 

69 name=self.name, 

70 dataset=self.dataset, 

71 ids=[self.ids[index]], 

72 columns=self.columns.slice(index, 1), 

73 data=self.data[index : index + 1], 

74 sample_axes=self.sample_axes, 

75 value_range=self.value_range, 

76 )
